Подключение

Настройки API

Укажи адрес backend и ключ доступа для библиотеки тестов.

Адрес API

Базовый URL сервера, например https://job-prep-api.onrender.com

Вводи домен без конечного слеша. Все запросы приложения отправляются на этот адрес.

Ключ интеграции

Для внешнего сайта и общей библиотеки. Личные тесты доступны после входа в аккаунт.

Ключ даёт право читать и создавать общие тесты. Не размещай его в публичном коде сайта. Введённый здесь ключ не сохраняется после закрытия вкладки.

Пользовательский аккаунт

Вход по email-коду. Для отправки кода на сервере должны быть настроены SMTP-переменные.
